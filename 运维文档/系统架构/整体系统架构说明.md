# 整体系统架构说明

## 1. 架构概览

```
用户 → CDN/WAF → API Gateway → 微服务集群 → 数据层
                                    ↓
                              消息队列 / 任务调度
```

## 2. 逻辑分层

| 层级 | 组件 | 说明 |
|------|------|------|
| 接入层 | CDN、WAF、Nginx Ingress | TLS 终结、限流、路由 |
| 网关层 | Kong / 自研 Gateway | 鉴权、路由、熔断 |
| 业务层 | 订单、支付、用户、商品等 40+ 服务 | K8s Deployment |
| 数据层 | MySQL、Redis、ES、Kafka | 各域独立实例或集群 |
| 可观测 | Prometheus、Loki、Jaeger | 指标、日志、链路 |

## 3. 部署环境

| 环境 | 用途 | 集群 |
|------|------|------|
| dev | 开发联调 | k8s-dev |
| staging | 预发验证 | k8s-stg |
| prod | 生产 | k8s-prod-hz / k8s-prod-sh |

## 4. 多活策略

- 华东（杭州）、华东（上海）双活，流量按地域 DNS 调度
- 数据库：各域主库本地，跨域异步复制（非双写）
- Redis：各机房独立 Cluster，会话 sticky 到同域

## 5. 依赖外部

- 对象存储 OSS
- 短信/邮件 SaaS
- 第三方支付 SDK

详细服务依赖见 [微服务依赖关系](./微服务依赖关系.md)。
