# 数据流与存储架构

## 1. 数据分类

| 类型 | 示例 | 存储 | 保留 |
|------|------|------|------|
| 交易数据 | 订单、支付流水 | MySQL | 7 年 |
| 缓存 | 会话、热点商品 | Redis | 按 TTL |
| 搜索 | 商品索引 | Elasticsearch | 与源同步 |
| 日志 | access、app log | Loki / OSS | 90 天 |
| 消息 | 订单事件 | Kafka | 7 天 |

## 2. 订单数据流

```
用户下单 → order-service 写 MySQL（主库）
         → 发 Kafka order.created
         → inventory 消费扣库存
         → search 消费更新索引（最终一致，延迟 < 5s）
```

## 3. 数据库拓扑

- **订单库**：1 主 2 从，ProxySQL 读写分离
- **用户库**：1 主 1 从
- **报表库**：从库延迟同步，只读

## 4. 备份策略

| 组件 | 方式 | RPO | RTO |
|------|------|-----|-----|
| MySQL | 全量 + binlog | 5 min | 4 h |
| Redis | RDB + AOF | 1 min | 1 h |
| ES | snapshot 至 OSS | 24 h | 8 h |

## 5. 合规

- PII 字段加密存储（手机号、身份证 hash）
- 跨境数据不出境，灾备仅在境内 Region
