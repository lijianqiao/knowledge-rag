# 20260402 Redis 内存溢出 RCA

## 1. 事件摘要

| 项目 | 内容 |
|------|------|
| 时间 | 2026-04-02 03:15–04:20 |
| 影响 | 缓存命中率从 92% 降至 61%，部分接口 RT 上升 |
| 根因 | 营销活动写入大量无 TTL 的 session key |
| 触发 | 大促预热接口上线 |

## 2. 现象

- 告警：`redis_memory_usage_ratio > 0.95`
- `evicted_keys` 每分钟 +8000
- 核心业务 key 被 LRU 淘汰

## 3. 处置

1. 紧急扩容 Redis 内存 32GB → 48GB
2. 识别大 key：`preheat:session:*` 约 180 万条，单 key 平均 4KB
3. 与开发协调批量设置 TTL 24h
4. 调整 maxmemory-policy 为 volatile-lru（仅淘汰有过期时间的 key）

## 4. 根因

- 新接口未遵循 key 命名与 TTL 规范
- Code review 未覆盖缓存设计
- 内存容量规划未考虑大促系数

## 5. 改进项

- 上线前强制填写「缓存设计 checklist」
- 每周 bigkeys 扫描接入 CI 报告
- 大促前 1 周容量评估
