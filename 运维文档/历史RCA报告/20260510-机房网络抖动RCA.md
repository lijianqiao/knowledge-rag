# 20260510 机房网络抖动 RCA

## 1. 事件摘要

| 项目 | 内容 |
|------|------|
| 时间 | 2026-05-10 11:20–11:55 |
| 影响 | 华东机房对外 API 间歇超时，错误率峰值 8% |
| 根因 | 核心交换机 STP 拓扑变更导致短时环路 |
| 触发 | 运营商割接误操作

## 2. 时间线

- 11:20 多服务上报 upstream timeout
- 11:25 网络组确认华东核心交换机 CPU 100%
- 11:32 隔离异常链路，环路消除
- 11:55 各服务错误率恢复基线

## 3. 技术细节

- 两条冗余链路同时处于 forwarding 状态约 6 分钟
- K8s 节点间 etcd 出现短暂选主抖动
- 未触发多活切流（抖动窗口 < SLA 切换阈值）

## 4. 改进项

1. 与运营商建立割接提前 72h 通知机制
2. 核心交换机启用 BPDU Guard 与 Loop Guard
3. 应用侧超时与重试策略 review（已完成）
