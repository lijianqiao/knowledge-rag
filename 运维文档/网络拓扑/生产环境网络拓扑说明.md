# 生产环境网络拓扑说明

## 1. 区域划分

```
Internet
    │
    ▼
┌─────────────┐
│ CDN / WAF   │
└──────┬──────┘
       │
┌──────▼──────────────────────────────────┐
│ DMZ（10.10.0.0/16）                      │
│  - LB 集群（F5 / 云 SLB）                │
│  - Nginx Ingress 节点                    │
└──────┬──────────────────────────────────┘
       │
┌──────▼──────────────────────────────────┐
│ 应用区（10.20.0.0/16）                   │
│  - K8s Worker 节点                       │
│  - 微服务 Pod                            │
└──────┬──────────────────────────────────┘
       │
┌──────▼──────────────────────────────────┐
│ 数据区（10.30.0.0/16）                   │
│  - MySQL / Redis / Kafka                │
│  （禁止直连 Internet）                   │
└─────────────────────────────────────────┘
```

## 2. 安全组策略（摘要）

| 源 | 目标 | 端口 | 说明 |
|----|------|------|------|
| DMZ LB | 应用区 Ingress | 443 | HTTPS |
| 应用区 | 数据区 MySQL | 3306 | 白名单 SG |
| 应用区 | 数据区 Redis | 6379 | 白名单 SG |
| 办公网 | 堡垒机 | 22 | 经 JumpServer |
| 任意 | 数据区 | * | 默认 DENY |

## 3. DNS

- 公网：`api.example.com` → CDN CNAME
- 内网：`*.internal.example.com` → 内网 DNS（Split Horizon）
- K8s：`*.svc.cluster.local` 集群内解析

## 4. 双机房互联

- 杭州 ↔ 上海：专线 10Gbps，延迟约 8ms
- 用途：DB 异步复制、管理流量、灾备同步
- 详见 [机房互联与 VPN 说明](./机房互联与VPN说明.md)

## 5. 排障入口

- 连通性：`mtr`、`tcping` 从堡垒机发起
- 抓包：需安全审批，数据区禁止随意 tcpdump
