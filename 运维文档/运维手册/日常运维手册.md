# 日常运维手册

## 1. 适用范围

适用于生产环境 Linux 主机、K8s 集群、中间件及核心业务系统的日常巡检与维护。

## 2. 每日巡检清单

| 时段 | 检查项 | 正常标准 | 异常处理 |
|------|--------|----------|----------|
| 09:00 | 核心服务健康检查 | HTTP 200 / Pod Ready | 按应急预案升级 |
| 09:30 | 监控大盘 | 无 P1/P2 未恢复告警 | 认领告警并记录 |
| 10:00 | 磁盘使用率 | 数据盘 < 80% | 清理日志或扩容 |
| 14:00 | 备份任务 | 昨夜备份 SUCCESS | 重跑并通知 DBA |
| 18:00 | 证书有效期 | 剩余 > 30 天 | 提交续期工单 |

## 3. 常用命令

```bash
# K8s 集群概览
kubectl get nodes
kubectl get pods -A | grep -v Running

# 磁盘与负载
df -h
uptime

# 近期 ERROR 日志（示例）
journalctl -p err --since "1 hour ago" | tail -50
```

## 4. 权限与审计

- 生产变更必须使用堡垒机 + MFA
- 禁止共享 root 账号
- 所有 sudo 操作记录至审计系统，保留 180 天

## 5.  escalation 路径

1. L1 值班工程师（15 分钟内响应）
2. L2 组件 Owner（30 分钟内介入）
3. SRE 负责人 / 业务负责人（P0 立即拉群）
