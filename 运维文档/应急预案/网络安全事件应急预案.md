# 网络安全事件应急预案

## 1. 事件类型

- DDoS / CC 攻击
- 未授权访问、账号泄露
- 恶意软件、勒索软件
- 数据泄露 suspected

## 2. 响应原则

1. **先隔离再分析**：阻断攻击面，保留证据
2. **最小权限**：应急账号限时、可审计
3. **同步安全团队**：所有 P0 安全事件 15 分钟内上报 SOC

## 3. DDoS / CC 处置

| 步骤 | 动作 |
|------|------|
| 1 | WAF 开启紧急 CC 规则，封禁异常 IP 段 |
| 2 | CDN 侧启用「I'm Under Attack」或限速 |
| 3 | 源站 Nginx 限 conn / req |
| 4 | 与运营商/云清洗中心联动（大流量） |

## 4. 入侵 suspected

1. 隔离受影响主机（安全组 deny all，保留管理通道）
2. 内存/磁盘快照，导出关键日志
3. 轮换可能泄露的密钥、Token、DB 密码
4. 溯源完成后重装或从干净镜像恢复

## 5. 证据保留

- 防火墙、WAF、access log 至少保留 90 天
- 应急期间操作记录写入 INC 工单
- 事件结束后 72 小时内提交安全复盘

## 6. 对外沟通

- 对外口径仅经 PR / 法务 / 安全负责人批准
- 涉及用户数据时按合规要求通知 regulator
